# Social image font

`BricolageGrotesque-Bold.ttf` is the static 700-weight, optical-size-12 instance of the existing Solta Site heading font. It is bundled for `app/opengraph-image.tsx`; social images do not need a remote font request at runtime.

Source: [Google Fonts CSS API](https://fonts.googleapis.com/css2?family=Bricolage+Grotesque:opsz,wght@12,700&display=swap), retrieved October 30, 2026. The font is distributed under the SIL Open Font License in `OFL.txt`, from the [Google Fonts source repository](https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque).
